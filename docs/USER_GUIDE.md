# AptoCAD Finance — user guide

## The basics

- The **top bar** sets what every screen shows: **Company / Civil / Mechanical / Corporate** and the
  **period** (default: financial year to date).
- **Ctrl + N** opens *New entry* from anywhere. **Ctrl + Enter** saves and starts another.
- Click any number, chart bar or row to see the entries behind it.
- Green = money in, grey/black = money out, amber = needs attention, red = overdue or negative.

## Every day (under a minute each)

| You want to… | Do this |
|---|---|
| Record a client payment | Ctrl+N → **Money in** → amount, account, category, client, project → Save |
| Record an Upwork payout | Money in → gross amount into the Upwork account → tick *A fee was deducted* → fee → Save |
| Record a bill you paid | Ctrl+N → **Money out** → amount, paid from, category (split if needed) → drop the receipt PDF → Save |
| Withdraw Payoneer/Upwork to the bank | Ctrl+N → **Move money** → from, to, amount sent, amount the bank credited → Save (exchange gain/loss is automatic) |
| Send money to the other department | Move money between the two departments' accounts — it is a *Dept transfer*, not profit |
| Attach a receipt later | Entries → click the entry → *Attach*, or drag the file onto the panel |
| Fix a mistake | Open the entry → **Edit**, or **Void** with a reason (never deleted) |

## Every month

1. **Payroll → Run payroll** on payday. Check APIT against the IRD table if needed. Download payslips.
2. **Payroll → EPF, ETF & APIT → Record payment** when you pay the statutory amounts.
3. **Recurring**: post the items that are due (Autodesk, rent, internet).
4. **Accounts → Reconcile** each account: import the statement CSV, match lines, create entries for bank
   charges, enter the closing balance until the difference is zero, **Finish reconciliation**.
5. Clear the **Needs attention** list on the dashboard.
6. Admin: **Settings → Month lock** up to the last day of the month.
7. Admin: **Reports → Accountant's pack** and save it to the shared drive.

## Invoices and bills

- **Invoices & quotes**: create, download a branded PDF, *Mark as sent*. When the client pays,
  choose *Record payment* — the Money-in form opens pre-filled and links the payment to the invoice.
- **Bills to pay**: add supplier bills with due dates; *Pay* opens a pre-filled Money-out form.

## Reports

- **Monthly summary** — the same layout as the Excel sheet, per department and company.
- **Profit & loss by department** — with the optional *fully loaded* view after shared costs.
- **Cash flow**, **Spending**, **Owed & owing** (ageing), **Tax monitor**, **Accountant's pack**.
- Every report exports to Excel; most to PDF.

## Budgets

**Budgets → Edit budget**: type monthly amounts per category (use → to copy the first month across).
**Budget vs actual** compares the year to date.
